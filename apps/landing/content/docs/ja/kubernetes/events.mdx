---
title: "イベント"
description: "Kubernetes イベントの閲覧とエクスポート。"
---

イベントページは、現在のクラスターとネームスペース範囲のイベントスナップショットを取得します。範囲の変更または手動更新で再取得します。継続的な watch ストリームではありません。

行にはタイプ、ネームスペース、関連 kind / オブジェクト、回数、理由、メッセージ、タイムスタンプが表示されます。Dockerman に対象 kind のルートがある場合だけリンクできます。

## フィルタ

現在 / すべてのネームスペース、Normal / Warning、オブジェクト kind、all / 5m / 15m / 1h、自由テキストで絞り込みます。動的な Reason セレクタはありません。

## エクスポート

絞り込んだ行を CSV または JSON でエクスポートできます。Kubernetes の Event はクラスターポリシーで期限切れになるため、耐久性のある監査ログではありません。
