title: "イベント"
description: "Kubernetes event の browse と export。"
---

Events page は current cluster と namespace scope の event snapshot を取得します。scope change または手動 refresh で再取得し、continuous watch stream ではありません。

row は type、namespace、involved kind/object、count、reason、message、timestamp を表示します。Dockerman に対象 kind の route がある場合だけ link できます。

## Filter

current/all namespace、Normal/Warning、object kind、all/5m/15m/1h、free text で絞り込みます。dynamic Reason selector はありません。

## Export

filtered rows を CSV または JSON で export できます。Kubernetes Event は cluster policy で expire するため、durable audit log ではありません。
