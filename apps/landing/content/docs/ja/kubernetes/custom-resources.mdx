---
title: "カスタムリソース"
description: "CRD を検出し、カスタムリソースのインスタンスを表示・編集する。"
---

Dockerman は接続中のクラスターから CustomResourceDefinition を検出し、API group、Kind、scope、served versions、age を一覧します。

CRD を選ぶとインスタンスを表示できます。表には名前、必要な場合の namespace、利用できる操作が出ます。他の対応リソースと同じサーバーサイドのドライランと競合チェックで YAML を編集できます。

## 現在の制限

- CRD 表はインスタンス数を計算しません。
- Kubernetes printer columns は表示しません。
- エディターは CRD OpenAPI schema を読み込まないため、クライアント側 schema 検証と補完はありません。
- 最終的な受付と検証は Kubernetes API server が行います。

CRD 自身が追加列や構造化 schema を公開していても、この制限は変わりません。
