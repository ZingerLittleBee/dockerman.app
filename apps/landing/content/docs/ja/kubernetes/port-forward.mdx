---
title: "ポートフォワードと DNS"
description: "Pod、Service、Deployment のポートを転送し、ローカル DNS を設定する。"
---

Dockerman は Pod、Service、Deployment のポートをローカルマシンへ転送できます。Kubernetes 設定に従って自動再接続も行えます。

## フォワードの開始

1. 対応リソースで**ポートフォワード**を選択します。
2. リモートポートと空いているローカルポートを選びます。
3. 開始後、表示されたローカルアドレスを使います。
4. 完了後はアクティブ一覧から停止します。

## 自動 DNS

フォワード開始時に `<target>.<namespace>.<suffix>` 形式の名前を登録します。デフォルト suffix は `k8s.local`、UDP DNS リスナーのデフォルトポートは `5353` です。

独立した DNS 有効化スイッチはなく、Dockerman は `/etc/hosts` を編集しません。

### プラットフォーム設定

- macOS：`/etc/resolver/<suffix>` を Dockerman の DNS ポートへ向けます。
- Linux：systemd-resolved などで suffix をローカル DNS へ送ります。
- Windows：システム resolver の自動統合は現在実装されていません。

suffix やポートの変更は新しい登録に適用されます。既存アプリが DNS をキャッシュしている場合があります。
