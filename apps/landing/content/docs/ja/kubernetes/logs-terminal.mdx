---
title: "Pod ログとターミナル"
description: "Pod log を表示し、running container で exec session を開きます。"
---

Pod から Logs を開き、regular container を選びます。viewer は [container logs](/ja/docs/docker/logs) と同じ実装済み search/follow control を使います。

current picker は init container log selection を保証しません。表示されない場合は `kubectl logs --init-container` を使ってください。

## Terminal

Terminal を開き、必要なら container を選び、shell command を選択または入力します。Dockerman は command を直接実行し、`bash`、`sh`、`zsh` の自動 probe はしません。

<Callout type="warn">
  target container の restart/delete で session は終了します。app restart 後に terminal history は復元されません。
</Callout>
