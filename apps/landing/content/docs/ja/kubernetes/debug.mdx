---
title: "デバッグアシスタント"
description: "既存プロセスのデバッグポートを転送し、エディターの attach 設定を生成する。"
---

デバッグアシスタントは、Pod 内ですでに実行中のプロセスへローカルデバッガーを接続します。Kubernetes のポートフォワードを作成し、エディター用の attach 設定を生成します。

## デバッグセッションの開始

1. 既存の Pod とコンテナを選択します。
2. 対応プリセットを選ぶか、リモートデバッグポートとソースパスを入力します。
3. セッションを開始します。
4. 生成された attach JSON をエディター設定へコピーします。
5. 完了後にセッションを停止し、ポートフォワードを閉じます。

## 対応しない機能

<Callout type="warn">
  Dockerman は一時的なツール Pod の作成、デバッグツールの注入、別 Pod のプロセス/ネットワーク namespace 共有、ボリュームのマウント、デバッグターミナルの起動を行いません。対象プロセスは選択したデバッグポートで既に待ち受けている必要があります。
</Callout>

コンテナに shell が含まれる場合は通常の [Pod ターミナル](/ja/docs/kubernetes/logs-terminal)を使用してください。
