Dockerman は、デスクトップから Docker、Podman、Kubernetes を管理する場所です。コンテナ、イメージ、クラスターの作業を一つの流れで進めたい開発者や運用者向けのネイティブアプリです。ローカルとリモートホストの操作は Docker と Podman、ワークロードの閲覧とデバッグは Kubernetes で行います。

## Dockermanがカバーする範囲

Dockerman は Docker と Kubernetes で画面を分けているので、ツールを切り替えずに、ローカルのコンテナ作業からクラスター作業へ移れます。Docker ホスト、イメージ、ボリューム、Compose プロジェクトを手元に置き、ワークロード、サービス、設定、Helm、ポッドのデバッグが必要になったら Kubernetes に切り替えてください。下のカードから始めてください。

## 主な機能

<Cards>
  <Card title="Dockerの完全なライフサイクル">
    コンテナの作成、実行、検査、ログ表示、ターミナル接続を行い、イメージ、ネットワーク、ボリューム、Composeプロジェクトを一箇所から管理します。
  </Card>
  <Card title="ネイティブKubernetes（フェーズ1）">
    ワンクリックでk3dを起動、または既存のkubeconfigを使用。ワークロード、Service、ConfigMap、RBAC、CRD、Helmリリースを閲覧します。
  </Card>
  <Card title="バックアップと復元">
    コンテナの設定、ファイルシステム、ボリュームを単一のtar.gzにスナップショットし、どこでも復元できます（v4.8.0で追加）。
  </Card>
  <Card title="イメージセキュリティ">
    Trivyでイメージをスキャンし、アプリを離れることなくDocker Hubを閲覧できます（v4.6.0で追加）。
  </Card>
  <Card title="WSL2 Docker Engine">
    Docker DesktopなしでWindows上でDockerを実行。DockermanがAlpine WSL2ディストリビューションをセットアップし、Dockerを自動インストールします（v4.3.0で追加）。
  </Card>
  <Card title="リモートホスト">
    SSHトンネル経由でリモートDockerデーモンに接続し、ホスト間をその場で切り替えます。
  </Card>
  <Card title="Podmanランタイムサポート">
    DockerのドロップインとしてPodmanを使用。Dockermanはランタイムを自動検出し、UIを合わせます（v5.1.0で追加）。
  </Card>
  <Card title="Homelab 自動化">
    バックグラウンドタスクスケジューラ、複数チャンネルの通知（Telegram、ntfy、Gotify、Discord、Webhook）、アラートルール、イメージアップグレード監視、ワンクリックの診断バンドル。
  </Card>
</Cards>
