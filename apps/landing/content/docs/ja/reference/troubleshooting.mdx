よくある問題と、それぞれを早く片付ける方法です。

## Dockerデーモンに接続できない

お使いのプラットフォームに合わせて、次のタブを使ってください。

<Tabs items={['macOS', 'Windows', 'Linux']}>
  <Tab>
    Docker Desktop が実行中であることを確認し、[設定 → Docker設定](/ja/docs/reference/settings#docker設定)で Dockerman が使うソケットパスを確認してください。
  </Tab>
  <Tab>
    [Windows](/ja/docs/platform/windows) で Docker Desktop と WSL2 エンジンのどちらを使うか選んでください。Dockerman が誤ったバックエンドを指している場合は、[設定 → Docker設定](/ja/docs/reference/settings#docker設定)で切り替えてください。
  </Tab>
  <Tab>
    ユーザーをdockerグループに追加し、[Linuxの権限](/ja/docs/platform/linux#docker-グループへのユーザ追加)に従ってください。
  </Tab>
</Tabs>

## Linuxでの権限エラー

Dockermanが`/var/run/docker.sock`にアクセスできない場合は、ユーザーをdockerグループに追加し、ログアウトして再度ログインし、`sudo`なしで`docker ps`が動作することを確認してください。

## WSL2セットアップウィザードが失敗する

WSL2 のパスは、Windows のトラブルシューティングを見てください：[Windowsプラットフォームのトラブルシューティング](/ja/docs/platform/windows#docker-desktopとwsl2-engineの切り替え)。

## SSHホスト接続が失敗する

接続情報を確認し、ポート 22 への外向き通信をブロックするファイアウォールルールがないか確認してください。詳しい設定手順については、[リモートホスト](/ja/docs/advanced/remote-hosts)をご覧ください。

## パフォーマンスの問題

- アイドル時のCPU使用率が高い場合、通常はLogsタブが大量のファイルセットをストリーミングしていることを意味します。使用していないタブは一時停止してください。
- 数百のコンテナでリストの読み込みが遅い場合、通常はまずステータスまたはComposeプロジェクトでフィルタリングする必要があることを意味します。
- Stats が遅い場合は、6h や 24h から 1h など、実際に出ている短い範囲に変えてください。

## Kubernetes：k3dが起動に失敗する

<Accordions>
  <Accordion title="ポート6443が既に使用中">
    他のKubernetesツールを停止するか、k3d APIポートを変更してから再試行してください。
  </Accordion>
  <Accordion title="vm.max_map_countが低すぎる">
    `sudo sysctl -w vm.max_map_count=262144`を実行し、再起動後も値を保持したい場合は`/etc/sysctl.conf`に永続化してください。
  </Accordion>
  <Accordion title="k3dバイナリのダウンロードに失敗">
    外向きHTTPSアクセスを確認し、ダウンロードを再試行してください。必要に応じて、エラーに表示されたパスにバイナリを手動で配置してください。
  </Accordion>
</Accordions>

## Kubernetes：kubeconfigのインポートに失敗

- kubeconfigをインポートする際に、正しいコンテキスト名を選択してください。
- 期限切れの認証情報を更新し、kubeconfigを再度エクスポートしてください。
- プロキシまたはファイアウォールの内側でインポートする前に、コマンドラインから`kubectl get ns`が動作することを確認してください。

## ログの収集

まず App Log ページを開いてください。問題を報告する場合は、App Log を書き出し、Dockerman のバージョンと一緒に添付してください。

## サポートを受ける

GitHub リポジトリへ、App Log の書き出しと、インストールパッケージまたはリリースのバージョンを添付してください。設定 → About ページはありません。
