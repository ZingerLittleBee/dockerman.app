title: "イベント"
description: "Docker daemon イベントのストリーム、フィルタ、保存、エクスポート。"
---

イベントページは、選択中の Docker ホストからイベントを受け取り、検索、フィルタ、詳細、エクスポートができます。

## 一時停止

一時停止中の新しいイベントは、表示中の一覧にも永続化キューにも入りません。あとで再生するためのバッファではなく、破棄されます。

## ローカル履歴

Dockerman はアプリデータディレクトリに、ホストごとの JSONL を保存します。1 ファイルは 5 MiB でローテーションし、現在のファイルに加えて最大 20 個のローテーション済みファイルを保持します。時間ベースの保持設定はありません。

## フィルタとエクスポート

ページに実際に出ているコントロールで、リソースタイプ、アクション、時刻、テキストを絞り込みます。利用できる場合は JSON または CSV でエクスポートできます。

<Callout type="warn">
  Docker イベントは状態遷移です。すべてのコマンドエラーや、操作した人物を記録する監査ログではありません。
</Callout>
