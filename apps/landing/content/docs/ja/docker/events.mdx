Events page は選択中の Docker host から event を受信し、search、filter、detail、export を提供します。

## Pause

pause 中の新しい event は visible list と永続化 queue に入りません。後で replay するための buffer ではなく、drop されます。

## Local history

Dockerman は app data directory に host ごとの JSONL を保存します。1 file は 5 MiB で rotate し、current file に加えて最大 20 rotated file を保持します。時間ベースの retention setting はありません。

## Filter と export

page に実際に表示される control で resource type、action、time、text を絞り込みます。利用可能な場合は JSON または CSV で export できます。

<Callout type="warn">
  Docker event は state transition であり、すべての command error や操作した人物を記録する audit log ではありません。
</Callout>
