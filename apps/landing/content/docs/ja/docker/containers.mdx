コンテナページで、選択中のランタイム上のコンテナを検索、確認、管理します。

## ライフサイクル

使えるアクションは、コンテナの状態とランタイムによって異なります。対応している場合は、開始、停止、再起動、一時停止、再開、名前変更、削除、検査、ログ、ターミナル、統計、クローン、コミット、バックアップ、リストアが表示されます。

<Callout type="info">
  一時停止はランタイムの pause API を使います。`SIGSTOP` を送るという契約ではありません。UI に force オプションがある場合は、実行中のコンテナも削除できます。先に停止する必要は必ずしもありません。
</Callout>

## 作成

作成ダイアログは、選んだローカルイメージと入力したオプションから設定を組み立てます。欠けているイメージの自動 pull や、作成後の自動開始は保証しません。必要なら先に pull し、作成後に明示的に開始してください。

作成前に、ポート、マウント、環境変数、リソース制限、再起動ポリシー、ネットワークを確認します。ランタイムが対応していないオプションは非表示になることがあります。

## 検査、クローン、コミット

- **Inspect** はランタイムが返すコンテナデータを表示します。
- **Clone** は対応する設定を作成フローへコピーしますが、ボリュームデータはコピーしません。
- **Commit** は書き込み可能なレイヤーをイメージとして保存します。マウントしたボリュームデータは含みません。

## バックアップとリストア

バックアップのアーカイブにはマニフェストと、選んだコンテナ、ボリューム、バインドマウントのデータが入ります。リストア前にプレビューしてください。任意のホストパスは自動的に安全とは判定されないため、各バインドマウントを確認してください。

リストアは対応するリソースを再作成します。元のネットワークが存在する保証はなく、復元されたコンテナが自動開始されるとは記載されていません。名前、ポート、ボリューム、ネットワーク、イメージを確認してから、必要なら明示的に開始してください。

<Callout type="warn">
  アーカイブは機密情報として扱ってください。ファイルシステム、環境変数、バインドマウントの内容が含まれることがあります。
</Callout>

## 一括アクション

ページの一括モードを有効にして、複数行を選びます。対象は現在のツールバーに出ているアクションだけです。通常の Ctrl/Cmd+Click や 1 文字ショートカットは契約ではありません。
