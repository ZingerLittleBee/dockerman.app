title: "Compose"
description: "Compose プロジェクトの管理と YAML 編集。"
---

Compose ページは、Docker Compose のラベルからプロジェクトを発見し、選択中の Docker ランタイムが対応するライフサイクル操作を提供します。Podman ターゲットでは利用できません。

## ライフサイクル

プロジェクトの状態に応じて、start、stop、restart、pull、up、remove が使えます。ボリューム削除のオプションは Compose に渡されます。Dockerman が名前付きボリュームや他の利用者を事前確認するわけではありません。

## YAML の編集

プロジェクトの Compose ファイルをエディタで開き、保存してから適用します。保存前に `docker compose config` は実行されず、完全なスキーマ検証やオートコンプリートも保証しません。重要なファイルは別途検証してください。

## `docker run` の変換

Run to Compose は一般的なフラグを YAML プレビューに変換します。未対応や高度なフラグは、保存とデプロイの前に確認してください。

## 現在の制限

プロジェクト単位の結合ログビューアはありません。厳選されたアプリテンプレートは **Apps** にあり、Compose ページの組み込みテンプレートエディタではありません。既存ファイルを再利用テンプレートとして保存する操作もありません。
