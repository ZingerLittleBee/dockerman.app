Compose page は Docker Compose label から project を発見し、選択中の Docker runtime が対応する lifecycle action を提供します。Podman target では利用できません。

## Lifecycle

project state に応じて start、stop、restart、pull、up、remove が使えます。volume removal option は Compose に渡され、Dockerman が全 named volume や他 consumer を事前確認するわけではありません。

## YAML edit

project の Compose file を editor で開き、save 後に apply します。save 前に `docker compose config` は実行されず、完全な schema validation/autocomplete も保証しません。

## `docker run` conversion

Run to Compose は一般的な flag を YAML preview に変換します。unsupported/advanced flag は deploy 前に確認してください。

## Current boundaries

project-level merged log viewer はありません。curated app template は **Apps** にあり、Compose page の built-in template editor ではありません。existing file を reusable template として保存する操作もありません。
