---
title: "ログ"
description: "Container log の stream、search、filter、copy、export。"
---

container から Logs を開くと output を follow します。pause は最新行への follow を止めるだけです。

## Fetch controls

time preset または custom range、最大 10,000 の tail、stdout/stderr filter を選べます。text、case-sensitive、regex search は load 済み row に対して行われ、server-side Docker query ではありません。

## Keyboard controls

実装済み shortcut は `/` または Ctrl/Cmd+F、match 用の Ctrl/Cmd+G と Shift+Ctrl/Cmd+G、follow/pause の `P`、Alt+C、Alt+R、newest/oldest の `g`/`G`、search clear の Escape です。`n`、`N`、Enter、Shift+Enter は契約ではありません。

## Export

toolbar から text/JSON を copy または export できます。relative/UTC/local timestamp format switch はありません。
