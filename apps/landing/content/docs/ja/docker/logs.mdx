---
title: "ログ"
description: "コンテナログのストリーム、検索、フィルタ、コピー、エクスポート。"
---

コンテナから Logs を開くと、出力を追従します。一時停止は最新行への追従を止めるだけで、コンテナ自体は変えません。

## 取得コントロール

時刻のプリセットまたはカスタム範囲、最大 10,000 の tail、stdout / stderr フィルタを選べます。テキスト、大文字小文字の区別、正規表現の検索は、読み込み済みの行に対して行われます。サーバー側の Docker クエリではありません。

## キーボード操作

実装済みのショートカットは、検索の `/` または Ctrl/Cmd+F、一致用の Ctrl/Cmd+G と Shift+Ctrl/Cmd+G、追従 / 一時停止の `P`、Alt+C、Alt+R、最新 / 最古の `g` / `G`、検索クリアの Escape です。`n`、`N`、Enter、Shift+Enter は契約ではありません。

## エクスポート

ツールバーからテキスト / JSON をコピーまたはエクスポートできます。タイムスタンプの表示は読み込んだ Docker ログに従います。相対 / UTC / ローカルの切り替えはありません。
