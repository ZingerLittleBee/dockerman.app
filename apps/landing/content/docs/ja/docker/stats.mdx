---
title: "統計"
description: "Container の live および historical resource chart。"
---

container から Stats を開き、CPU、memory、network、disk、process data を表示します。通常の Stats route は container 選択が必要で、host-wide overview dashboard ではありません。

## Time range

- Live: 1m、5m、15m。
- Historical: 1h、6h、24h、7d。

historical data は stats aggregation と retention task に依存します。raw sample は 1 hour、5-minute aggregate は 7 days 保持されます。

## Chart

CPU と memory は ring gauge と history chart、network と disk は rate と expandable detail を表示します。ring color は表示上の表現で、alert threshold の契約ではありません。

## Compare

Compare では最大 6 host/container pair を選択できます。historical aggregate を使い、live mode は無効になります。選択は local に保存されます。

<Callout type="info">
  historical range が空なら、その期間の sample が記録されていません。Docker から後で再構築されることはありません。
</Callout>
