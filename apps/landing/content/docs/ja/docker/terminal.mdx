---
title: "ターミナル"
description: "実行中のコンテナでインタラクティブ shell を開きます。"
---

実行中のコンテナから **Terminal** を開くと、xterm.js の対話セッションが始まります。

## Shell command

Dockerman はセッションで選択した shell command を実行します。複数の shell を自動探索したり `sh` で再試行したりはしません。command が存在しない場合は、image 内にあるものを選択してください。

## 現在の controls

terminal toolbar と terminal 標準の選択、copy、paste、scroll を使います。desktop settings には global terminal font、cursor、theme の設定や、独自の terminal shortcut map はありません。

<Callout type="warn">
  コンテナを停止すると session は終了します。distroless image には shell 自体がない場合があります。
</Callout>
