ボリューム内でも実行中のコンテナ内でも、ファイルブラウザの使い方は同じです。両方の入り口と、ファイル操作をまとめています。

## エントリーポイント

<Tabs items={['ボリュームから', 'コンテナから']}>
  <Tab>
    Volumes ページを開き、ボリュームを選んで Browse をクリックします。ルートは `/volume/<name>/browse` のようになります。
  </Tab>
  <Tab>
    実行中のコンテナを開き、Files をクリックするか `/file` を直接開きます。停止したコンテナは書き込み可能なファイルブラウザを公開しません。
  </Tab>
</Tabs>

## ナビゲーション

左側のツリーでフォルダを移動し、上部のパンくずリストで上の階層に戻り、フォルダをダブルクリックして下ります。素早く戻る場合は Back または Home を使います。パス入力欄から、既知のパスへ直接移動できます。

## ファイルのプレビュー

v4.4.0で追加されました。

プレビューは、ダウンロードする前に中身を確認したい一般的なファイル形式を扱います。

| タイプ | フォーマット |
| --- | --- |
| テキストとコード | `.txt`、`.log`、`.json`、`.yaml`、`.toml`、`.ini`、`.env`、ソースコードファイル |
| Markdown | `.md`、`.mdx` |
| 画像 | `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.svg` |
| PDF | `.pdf` |
| 動画 | `.mp4`、`.webm` |
| 音声 | `.mp3`、`.wav`、`.ogg` |

<Callout type="info">
  10MB を超えるファイルはダウンロード専用です。Dockerman がファイル全体をメモリに読み込まないようにしています。
</Callout>


## ファイルの編集

v4.4.0で追加されました。

Monaco でテキストファイルやコードファイルを開き、変更してからボリュームまたはコンテナに保存します。保存または破棄するまで、未保存の変更は表示されたままです。

<Callout type="warn">
  実行中のコンテナ内のファイルを編集すると、コンテナの書き込み可能なレイヤーが変更されますが、イメージは変更されません。同じイメージから再起動すると、コンテナをコミットしない限り編集内容は破棄されます。詳細は[実行中コンテナのコミット](/ja/docs/docker/containers#実行中コンテナのコミット)を参照してください。
</Callout>

### エディタのセーフガード

- **モード保持** — 保存しても、書き込み時にリセットされず、元の Unix 権限（`0644`、`0755` など）が残ります。
- **バイナリ検出** — エディタは NUL バイトを含むファイルを開かず、ダウンロードの確認を出します。拡張子が実体と違う場合の破損を防ぎます。
- **1 MB の編集上限** — 1 MB を超えるファイルはエディタ内で読み取り専用です。大きな変更が必要なら、ダウンロードしてローカルで編集し、再アップロードしてください。


## アップロードとダウンロード

明示的なアップロード操作で、ローカルのファイルまたはフォルダを選びます。ダウンロードは単一ファイル向けです。ドラッグ＆ドロップのアップロード、複数ファイルのダウンロード、フォルダの自動 ZIP ダウンロードは、現在の機能としては案内していません。

## ファイルの削除

v4.4.0で追加されました。

Delete は、選んだファイルやフォルダを現在のボリュームまたはコンテナから削除します。

<Callout type="warn">
  ファイルの削除は元に戻せず、ホストのゴミ箱をバイパスします。
</Callout>

削除は、現在選んでいる 1 件に対して行います。上記の複数選択ショートカットや一括削除はありません。
