ボリュームの一覧、作成、検査、クリーンアップができます。中身を見る場合は [ファイル](/ja/docs/docker/files) へ進んでください。

## ボリュームリスト

ボリュームリストには名前、ドライバー、マウントポイント、サイズ、作成時刻が出ます。並べ替えとフィルタで目的のボリュームを見つけられます。

## ボリュームの作成

<Steps>
  <Step>
    ### 名前とドライバーの選択

    ボリューム名と、ダイアログが現在出す `local`、`nfs`、`cifs` のいずれかを選びます。インストール済み Docker プラグインから動的に作られる一覧ではありません。
  </Step>
  <Step>
    ### ドライバーオプション（任意）

    local ドライバーの NFS マウント設定など、ドライバー固有のオプションを追加できます。
  </Step>
  <Step>
    ### ラベル（任意）

    後でボリュームをグループ化または検索したい場合にラベルを追加してください。
  </Step>
</Steps>

## ボリュームファイルの参照

[ファイル](/ja/docs/docker/files) でボリュームの中身を参照し、プレビュー、テキスト編集、アップロード、ダウンロード、複数選択アクションを扱えます。

## ボリュームの検査

検査を開くと、マウントポイント、ドライバーオプション、ラベル、スコープ、いまボリュームを使っているコンテナ一覧を含むボリューム JSON を確認できます。

## 未使用ボリュームのクリーンアップ

クリーンアップは選択中のランタイムに prune を依頼し、未使用かどうかの判定はランタイムが行います。実行前に確認ダイアログを見てください。

<Callout type="warn">
  クリーンアップは、残したい名前付きボリュームも含め、未使用ボリュームをすべて消します。明示的に消す場合は削除を使ってください。
</Callout>
