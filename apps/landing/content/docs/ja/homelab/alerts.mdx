Alerts page は現在 2 つの built-in preset を管理します。

- **Restart loop**: restart burst で trigger。
- **Container crash**: non-zero exit で trigger。

preset ごとに enable/disable、追加 notification channel、reset to defaults を操作できます。system channel は常に残ります。

## Current limitation

**Create rule** button は disabled で Coming Soon です。custom-rule editor、target selector、severity、silence window、generic cooldown form はありません。health/resource-threshold rule を UI から作成できるという説明は現行 release には当てはまりません。

## Recent alerts

rule name、短い context、time の compact feed です。searchable column-persistent data table ではありません。
