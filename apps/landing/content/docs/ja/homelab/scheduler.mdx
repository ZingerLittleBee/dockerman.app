title: "バックグラウンドタスク"
description: "Scheduler task と recent run を確認します。"
---

Tasks page は task record、schedule、next run、last result、config、recent run を表示します。

| Kind | Default interval |
| --- | --- |
| `stats_aggregation` | 5 minutes |
| `stats_retention_prune` | 60 minutes |

image watch を設定すると関連 task が現れる場合があります。

## Current limitations

**Create task** は disabled で Coming Soon です。seeded built-in task は UI で locked 扱いとなり、enable switch、schedule edit、Run now は使えません。既存の non-built-in record がある場合だけ操作が表示されます。

scheduler は app process が alive の間だけ動きます。full quit すると停止します。
