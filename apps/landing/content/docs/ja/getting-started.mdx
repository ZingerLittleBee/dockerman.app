Dockerman をインストールし、最初の接続まで進めます。Windows で Docker Desktop を使いたくない場合は、Windows プラットフォームガイドの組み込み WSL2 パスを使ってください：[Windows](/ja/docs/platform/windows)。

## 前提条件

<Callout type="info">
  コンテナを管理するには、先に Docker または Podman ランタイムが必要です。Dockerman は起動時にランタイムを自動検出し、UI を合わせます。Windows では、[Windows プラットフォームガイド](/ja/docs/platform/windows) の組み込み WSL2 Docker Engine パス経由で、Dockerman が Docker デーモンを用意できます。
</Callout>

## インストール

<Tabs items={['macOS', 'Windows', 'Linux']}>
  <Tab>
    <Steps>
      <Step>
        ### DMGのダウンロード

        ダウンロードページからmacOS用DMGをダウンロードしてください。
      </Step>
      <Step>
        ### 開いてApplicationsにドラッグ

        DMGを開き、DockermanをApplicationsフォルダにドラッグしてください。
      </Step>
      <Step>
        ### Dockermanの起動

        ApplicationsまたはSpotlightからDockermanを起動してください。
      </Step>
    </Steps>
  </Tab>
  <Tab>
    <Steps>
      <Step>
        ### MSIのダウンロード

        ダウンロードページからWindows用MSIをダウンロードしてください。
      </Step>
      <Step>
        ### インストーラーの実行

        インストーラーを実行し、プロンプトに従ってください。
      </Step>
      <Step>
        ### Dockermanの起動

        Dockermanを起動し、初回起動で組み込み Docker Engine パスを使う場合は、WSL2 セットアップウィザードを進めてください。詳細は[Windowsプラットフォームガイド](/ja/docs/platform/windows)をご覧ください。
      </Step>
    </Steps>
  </Tab>
  <Tab>
    <Steps>
      <Step>
        ### パッケージのインストール

        お使いのディストリビューションに合ったパッケージをインストールしてください。`.deb`、`.rpm`、またはAppImageビルドがあります。その後、[Linuxプラットフォームガイド](/ja/docs/platform/linux)に従ってください。
      </Step>
      <Step>
        ### dockerグループへのユーザー追加

        以下を実行してください：

        ```bash
        sudo usermod -aG docker $USER
        ```

        新しいグループメンバーシップが有効になるよう、ログアウトして再度ログインしてください。
      </Step>
      <Step>
        ### Dockermanの起動

        デスクトップメニューから Dockerman を起動してください。公開パッケージは、`PATH` 上に `dockerman` という GUI 実行ファイルがあることを保証しません。
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 初回起動

<Steps>
  <Step>
    ### 接続ダイアログ

    Dockermanは自動的にローカルDockerに接続を試み、進捗状況またはエラーを表示します。

  </Step>
  <Step>
    ### ランタイムソースの選択

    ローカルソケット、TCP エンドポイント、または SSH ホストを指定してください。ランタイム設定は Auto / Docker / Podman から選びます。Auto は利用できるランタイムを検出し、先に Docker、次に Podman を試します。
  </Step>
  <Step>
    ### データの初期化

    Dockermanはコンテナ、イメージ、ネットワーク、ボリューム、およびComposeプロジェクトを並列で読み込みます。
  </Step>
  <Step>
    ### ダッシュボード

    実行中および停止したコンテナのスナップショットと、リアルタイムチャートを確認できます。

  </Step>
</Steps>

## システム要件

| プラットフォーム | 最低バージョン | アーキテクチャ |
| --- | --- | --- |
| macOS | 11 (Big Sur) | Intel、Apple Silicon、Universal |
| Windows | サポート対象の Windows 10 / 11 ビルド | x86_64 |
| Linux | 現行のデスクトップ向けディストリビューション | x86_64 |

コンテナ管理には、対応する Docker または Podman エンドポイントが必要です。プロジェクトは、別途検証したエンジン最低バージョンの一覧を公開していません。Windows では任意の WSL2 パスで Docker を用意できます。
