---
title: "macOS"
description: "macOS で Docker Desktop、互換ソケット、または Apple Container を使用する。"
---

macOS 版 Dockerman は 1 つの Universal DMG として公開されます。インストール前にリリースページで現在の資産と署名を確認してください。

## インストール

<Steps>
  <Step>
    ### DMGのダウンロード

    リリースページから Universal DMG をダウンロードします。
  </Step>
  <Step>
    ### 開いてApplicationsにドラッグ

    DMGを開き、DockermanをApplicationsにドラッグしてください。
  </Step>
  <Step>
    ### Dockermanの起動

    ApplicationsまたはSpotlightからDockermanを起動し、macOSが求めた場合は初回起動プロンプトを承認してください。
  </Step>
</Steps>

## コンテナバックエンド

Dockerman は Docker Desktop または Docker 互換ソケットに接続できます。自動検出されない場合は、設定 → Docker でソケットパスを指定してください。

<Callout type="info">
  `/var/run/docker.sock`や`~/.docker/run/docker.sock`などのDocker互換ソケットも動作します。Dockermanがソケットを自動検出しない場合は、設定→Docker設定でパスを設定してください。
</Callout>

macOS 26 以降を実行する Apple Silicon Mac では、Apple Container バックエンドも利用できます。エンジンのオンボーディングまたは設定で **Apple Container** を選択してください。Intel Mac と古い macOS では利用できません。

## メニューバーとトレイ

Dockerman は、よく使うアプリ操作のためのメニューバーアイコンを追加します。設定 → 一般では、標準アイコンと CPU/メモリ表示を切り替えられます。

## Apple Silicon に関する注意事項

Apple Silicon でコンテナを実行する前に、イメージのプラットフォームを確認してください。多くの公開イメージでは `amd64` がデフォルトのため、利用可能であれば `arm64` バリアントを使用するか、`--platform=linux/arm64` を明示的に設定してください。

## トラブルシューティング

- 「Socket not found」は、Docker Desktop が実行されていないか、Dockerman が誤ったソケットパスを使用していることを示します。
- Gatekeeper によって Dockerman がブロックされた場合は、アプリを右クリックし、初回起動時に**開く**を選択してください。
