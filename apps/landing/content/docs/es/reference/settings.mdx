Configuración usa una navegación izquierda y un panel desplazable. Ábrela desde el engranaje, la bandeja del sistema o [Spotlight](/es/docs/advanced/spotlight).

## General

General contiene:

- Activación y estado de la licencia
- Shell predeterminado del terminal (`/bin/sh`, `/bin/bash`, `/bin/zsh` o una ruta personalizada)
- Estilo de la barra de menús: icono normal o estadísticas de CPU/memoria
- Atajo de Spotlight personalizable, con valor inicial `Cmd/Ctrl + ;`

La aplicación actual no tiene ajustes de fuente, cursor o tema del terminal, cierre a la bandeja ni edición del menú de bandeja.

## Barra lateral

Elige qué elementos se muestran en la navegación principal y de Kubernetes. Ocultar un elemento no deshabilita la función. **Restablecer** recupera los valores iniciales.

## Motor

Elige Docker o Apple Container como motor local. Docker incluye:

- Preferencia Auto, Docker o Podman
- Conexión por socket local o TCP
- Ruta de socket personalizada y prueba de conexión
- Seguimiento de actualizaciones de imágenes

Dockerman no inicia, detiene ni cambia los recursos de Colima o Podman machine. Consulta [Colima y Podman](/es/docs/platform/colima-podman).

## Kubernetes

Configura los valores de port forwarding y DNS automático. El registro DNS se crea al iniciar un forward; no existe un interruptor de activación independiente. Consulta [Port Forward y DNS](/es/docs/kubernetes/port-forward).

## Apps

Configura las fuentes de plantillas y la raíz de datos del host que usa Apps.

## Notificaciones

La página actual lista canales configurados y envía pruebas. La interfaz no ofrece un flujo completo para añadir, editar, deshabilitar o eliminar. Consulta [Notificaciones](/es/docs/homelab/notifications) para el almacenamiento y la seguridad.

## Seguridad

- Binario, versión, actualización y valores de escaneo de Trivy cuando el motor lo admite
- Analítica anónima del producto

La analítica está activada por defecto y se puede desactivar aquí. La aplicación actual no tiene interruptor de informes de fallos.

## CLI

Instala, actualiza o elimina `dockerman` y consulta los comandos para las integraciones de asistentes compatibles. Consulta el [resumen de CLI](/es/docs/cli).

## Ajustes que no existen

Dockerman no tiene ahora un panel de Tareas ni Configuración → Acerca de. Las páginas de tareas y alertas indican cuándo sus flujos de creación aún no están disponibles.
