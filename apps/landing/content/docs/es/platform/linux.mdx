Dockerman se distribuye como `.deb`, `.rpm` o AppImage para instalarlo en la distribución que ya usas.

## Instalación

<Tabs items={['.deb', '.rpm', 'AppImage']}>
  <Tab>
    ```bash
    sudo dpkg -i Dockerman_*_amd64.deb
    sudo apt-get install -f
    ```

    Instala el paquete `.deb` en Debian o Ubuntu.
  </Tab>
  <Tab>
    ```bash
    sudo rpm -i Dockerman-*-1.x86_64.rpm
    # o
    sudo dnf install Dockerman-*-1.x86_64.rpm
    ```

    Instala el paquete `.rpm` en Fedora o RHEL.
  </Tab>
  <Tab>
    ```bash
    chmod +x Dockerman_*_amd64.AppImage
    ./Dockerman_*_amd64.AppImage
    ```

    La AppImage se ejecuta directamente y no ofrece una opción `--install` de Dockerman.
  </Tab>
</Tabs>

## Configurar Docker Engine

Sigue las instrucciones oficiales de Docker Engine en [docs.docker.com/engine/install/](https://docs.docker.com/engine/install/) y comprueba que el daemon esté en ejecución. Dockerman no publica ahora una versión mínima de Docker Engine probada por separado.

## Permisos

<Steps>
  <Step>
    ### Añade tu usuario al grupo docker

    ```bash
    sudo usermod -aG docker $USER
    ```
  </Step>
  <Step>
    ### Cierra sesión y vuelve a iniciarla

    La membresía del grupo solo se aplica a las sesiones nuevas.
  </Step>
  <Step>
    ### Verifica el acceso

    Ejecuta `docker ps` sin `sudo`.
  </Step>
</Steps>

<Callout type="warn">
  Estar en el grupo `docker` equivale a acceso root en el host. Usa Docker rootless si necesitas un límite más estricto.
</Callout>

## Servidores de pantalla

Dockerman puede ejecutarse con Wayland o X11. El comportamiento de los atajos globales depende del entorno de escritorio y su integración con Tauri/WebView; Dockerman no implementa un backend propio de atajos de xdg-desktop-portal.

## Integración con Freedesktop

Dockerman instala un archivo `.desktop` para aparecer en el menú de aplicaciones. El icono de la bandeja usa la especificación StatusNotifierItem, soportada por KDE, GNOME con extensiones, XFCE y MATE.

## Solución de problemas

<Accordions>
  <Accordion title="comando docker no encontrado">
    Instala Docker Engine primero y abre una shell nueva para que tu PATH reconozca el CLI de Docker.
  </Accordion>
  <Accordion title="Permiso denegado en /var/run/docker.sock">
    Añade tu usuario al grupo `docker` y cierra sesión y vuelve a iniciarla para que la membresía surta efecto.
  </Accordion>
  <Accordion title="Icono de bandeja no visible">
    Instala una extensión StatusNotifierItem para tu entorno de escritorio. GNOME suele necesitar AppIndicator y KStatusNotifierItem Support.
  </Accordion>
</Accordions>
