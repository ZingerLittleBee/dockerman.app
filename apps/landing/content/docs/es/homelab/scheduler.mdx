La página muestra registros, horario, siguiente ejecución, último resultado, configuración y ejecuciones recientes.

| Tipo | Intervalo predeterminado |
| --- | --- |
| `stats_aggregation` | 5 minutos |
| `stats_retention_prune` | 60 minutos |

También pueden aparecer tareas de seguimiento de imágenes.

## Limitaciones actuales

**Crear tarea** está deshabilitado y marcado como Próximamente. Las tareas integradas están bloqueadas: no ofrecen interruptor, edición de horario ni Run now. Esos controles solo pueden aparecer en registros no integrados que ya existan.

El programador funciona mientras viva el proceso de la app; un cierre completo lo detiene.
