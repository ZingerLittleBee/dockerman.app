La página muestra registros, horario, siguiente ejecución, último resultado, configuración y runs recientes.

| Tipo | Intervalo predeterminado |
| --- | --- |
| `stats_aggregation` | 5 minutos |
| `stats_retention_prune` | 60 minutos |

También pueden aparecer tareas de image watch.

## Limitaciones actuales

**Crear tarea** está deshabilitado y marcado Próximamente. Las tareas integradas están bloqueadas: no ofrecen toggle, edición de horario ni Run now. Esos controles sólo pueden aparecer para registros no integrados ya existentes.

El scheduler funciona mientras viva el proceso de la app; un cierre completo lo detiene.
