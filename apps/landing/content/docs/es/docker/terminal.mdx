---
title: "Terminal"
description: "Abre un shell interactivo en un contenedor en ejecución."
---

Abre **Terminal** desde un contenedor en ejecución para iniciar una sesión interactiva de xterm.js.

## Comando de shell

Dockerman ejecuta el comando elegido para la sesión. No prueba automáticamente varios shells ni reintenta con `sh`; si el comando no existe, elige uno presente en la imagen.

## Controles actuales

Usa la barra del terminal y el comportamiento nativo de selección, copia, pegado y scroll. La configuración de escritorio no ofrece preferencias globales de fuente, cursor o tema del terminal, ni promete un mapa propio de atajos.

<Callout type="warn">
  Detener el contenedor termina la sesión. Una imagen distroless puede no contener ningún shell.
</Callout>
