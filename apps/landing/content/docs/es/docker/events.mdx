---
title: "Eventos"
description: "Transmite, filtra, persiste y exporta eventos del daemon Docker."
---

La página Eventos recibe eventos del host Docker seleccionado y ofrece búsqueda, filtros, detalles y exportación.

## Pausa

Mientras está pausada, los eventos nuevos no entran en la lista ni en la cola persistente. Se descartan, no se almacenan para reproducirlos después.

## Historial local

Dockerman guarda JSONL por host en el directorio de datos. Cada fichero rota a 5 MiB y se conservan hasta 20 ficheros rotados más el actual. No hay un ajuste de retención por tiempo.

## Filtros y exportación

Usa los controles visibles para filtrar por tipo, acción, tiempo y texto. Exporta el resultado como JSON o CSV cuando esté disponible.

<Callout type="warn">
  Los eventos Docker describen transiciones de estado; no son un registro de auditoría completo de errores o identidades humanas.
</Callout>
