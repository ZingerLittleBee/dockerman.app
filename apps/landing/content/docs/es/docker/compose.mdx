La página descubre proyectos por labels Docker Compose y ofrece acciones soportadas por el runtime Docker. No está disponible para targets Podman.

## Ciclo de vida

Según el estado puedes iniciar, detener, reiniciar, pull, up o eliminar. La opción de volúmenes se reenvía a Compose; Dockerman no enumera previamente todos los volúmenes nombrados ni otros consumidores.

## Editar YAML

Abre el fichero, guarda y aplica cuando proceda. Guardar no ejecuta `docker compose config` y el editor no promete validación/autocomplete completo del schema. Valida aparte los cambios importantes.

## Convertir `docker run`

Run to Compose transforma flags comunes en una vista YAML. Revisa flags no soportados antes de guardar y desplegar.

## Límites actuales

No hay visor combinado de logs de proyecto. Las plantillas curadas viven en **Apps**, no en un editor Compose, y esta página no guarda ficheros existentes como plantillas reutilizables.
