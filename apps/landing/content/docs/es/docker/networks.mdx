Lista redes, crea otras nuevas y conecta o desconecta contenedores.

## La lista de redes

Muestra el nombre, el controlador, el ámbito, cuántos contenedores hay conectados y la subred. Las redes integradas como `bridge`, `host` y `none` van marcadas para que no las elimines por error.

## Crear una red

<Steps>
  <Step>
    ### Elige un nombre y un controlador

    En Docker puedes elegir `bridge`, `host`, `overlay`, `macvlan` o `none`. Apple Container no muestra el selector de controlador.
  </Step>
  <Step>
    ### Configurar IPAM (opcional)

    Configura la subred, la puerta de enlace y el rango de IP si necesitas direccionamiento propio.
  </Step>
  <Step>
    ### Etiquetas (opcional)

    Añade etiquetas clave-valor para organizar o automatizar la red más adelante.
  </Step>
</Steps>

<Callout type="info">
  Las redes overlay requieren el modo Swarm en el daemon.
</Callout>

## Conectar y desconectar contenedores

Abre una red, selecciona Conectar contenedor y elige el contenedor de destino y un alias opcional. Usa Desconectar en la misma vista para quitar el contenedor de la red.

## Inspeccionar una red

Abre Inspeccionar para revisar el JSON de la red: opciones del controlador, configuración de IPAM y contenedores conectados con sus direcciones IP y alias.

## Eliminar y purgar

Eliminar quita una sola red después de desconectar los contenedores unidos. Purgar elimina todas las redes que no use al menos un contenedor.

<Callout type="warn">
  Las redes integradas (`bridge`, `host`, `none`) no pueden eliminarse. Purgar las omite.
</Callout>
