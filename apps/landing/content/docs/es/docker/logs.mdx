---
title: "Logs"
description: "Transmite, busca, filtra, copia y exporta logs de contenedores."
---

Abre Logs desde un contenedor para seguir su salida. Pausar sólo detiene el seguimiento de la última línea.

## Controles de carga

Elige un rango, un tail de hasta 10.000 líneas y stdout o stderr. La búsqueda de texto, mayúsculas y regex opera sobre filas ya cargadas; no es una consulta Docker server-side.

## Teclado

Los atajos implementados incluyen `/` o Ctrl/Cmd+F, Ctrl/Cmd+G y Shift+Ctrl/Cmd+G para coincidencias, `P` para pause/follow, Alt+C, Alt+R, `g`/`G` para más nuevo/más antiguo y Escape para limpiar. `n`, `N`, Enter y Shift+Enter no son atajos documentados.

## Exportar

La barra permite copiar o exportar texto/JSON. No existe el selector antes documentado de timestamp relativo/UTC/local.
