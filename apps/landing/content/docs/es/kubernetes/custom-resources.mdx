---
title: "Recursos personalizados"
description: "Descubre CRD y consulta o edita instancias de recursos personalizados."
---

Dockerman descubre CustomResourceDefinition en el clúster conectado y muestra API group, Kind, scope, served versions y age.

Selecciona un CRD para consultar sus instancias. La tabla muestra nombre, namespace cuando corresponde y acciones disponibles. Puedes inspeccionar el objeto y editar YAML con el mismo dry-run de servidor y control de conflictos que otros recursos compatibles.

## Limitaciones actuales

- La tabla de CRD no calcula el número de instancias.
- Dockerman no renderiza printer columns de Kubernetes.
- El editor no carga el esquema OpenAPI del CRD para validar o completar en el cliente.
- La aceptación y validación finales corresponden al API server de Kubernetes.

Estas limitaciones también aplican cuando el CRD publica columnas adicionales o un esquema estructural.
