Configuración y almacenamiento agrupa las fuentes de datos y los almacenes de los que dependen las cargas de trabajo.

## ConfigMaps

Abre un ConfigMap para revisar claves, valores y YAML. Edítalo cuando tengas que cambiar la configuración de una aplicación. Dockerman comprueba la versión del recurso antes de guardar, así que avisa si alguien más editó el mismo ConfigMap mientras trabajabas. Elimina un ConfigMap desde la lista cuando ya no haga falta.

<Callout type="info">
  Editar un ConfigMap no reinicia los pods que lo montan. Actualiza el Deployment o StatefulSet propietario si necesitas que los datos nuevos surtan efecto.
</Callout>

## Secrets

Abre un Secret para inspeccionar tipo, claves y valores. La lista muestra tipos habituales como `Opaque`, `kubernetes.io/tls` y `kubernetes.io/dockerconfigjson`. Al editar se aplica la misma detección de conflictos por versión de recurso que en ConfigMaps.

Los valores binarios se pueden descargar a un archivo local. Elimina un Secret desde la lista cuando ya no haga falta.

<Callout type="warn">
  Revelar muestra los valores del secreto en texto plano. Quien vea la pantalla en ese momento puede leerlos.
</Callout>

## PersistentVolumeClaims

La lista muestra la fase, el PersistentVolume vinculado, la clase de almacenamiento, los modos de acceso y la capacidad de cada reclamación. Elimina un PVC desde la lista cuando la reclamación esté liberada y ya no haga falta.

## PersistentVolumes

Los PersistentVolumes tienen su propia página, además de la vista por reclamación. Úsala para revisar el almacenamiento con ámbito de clúster, con independencia de cualquier namespace.

| Columna | Descripción |
| --- | --- |
| Nombre | El nombre del PV |
| Capacidad | Capacidad total |
| Modos de acceso | `RWO`, `ROX`, `RWX` o `RWOP` |
| Política de reclamación | `Retain`, `Delete` o `Recycle` |
| Estado | `Available`, `Bound`, `Released` o `Failed` |
| Claim | El PVC `namespace/name` vinculado, si existe |
| StorageClass | La clase que provisionó el volumen |

Abre un PV para ver la especificación completa, incluida la fuente de volumen (driver CSI, hostPath, NFS, etc.).

## StorageClasses

La lista muestra las opciones de almacenamiento del clúster: provisionador, política de reclamación, modo de vinculación de volúmenes y marcador de clase predeterminada.

## Namespaces

También hay páginas para LimitRange, ResourceQuota y PodDisruptionBudget.

La página permite listar, crear y eliminar namespaces. Eliminar uno puede borrar recursos namespaced; la UI no promete reproducir cada aviso de cascada que devuelve la API.
