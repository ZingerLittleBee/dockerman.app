---
title: "Primeros pasos"
description: "Instala Dockerman y conéctate al primer runtime de Docker o Podman."
---

Usa esta página para instalar Dockerman y hacer la primera conexión. En Windows, si quieres evitar Docker Desktop, sigue la ruta WSL2 de la guía [Windows](/es/docs/platform/windows).

## Requisitos previos

<Callout type="info">
  Tiene que haber un runtime de Docker o Podman antes de gestionar contenedores. Dockerman detecta cuál está en ejecución y adapta la interfaz. En Windows puede aprovisionar un Docker Engine con la ruta WSL2 integrada; ver la [guía de la plataforma Windows](/es/docs/platform/windows).
</Callout>

## Instalación

<Tabs items={['macOS', 'Windows', 'Linux']}>
  <Tab>
    <Steps>
      <Step>
        ### Descarga el DMG

        Descarga el DMG de macOS desde la página de Descargas.
      </Step>
      <Step>
        ### Abre y arrastra a Aplicaciones

        Abre el DMG y arrastra Dockerman a Aplicaciones.
      </Step>
      <Step>
        ### Inicia Dockerman

        Inicia Dockerman desde Aplicaciones o Spotlight.
      </Step>
    </Steps>
  </Tab>
  <Tab>
    <Steps>
      <Step>
        ### Descarga el MSI

        Descarga el MSI de Windows desde la página de Descargas.
      </Step>
      <Step>
        ### Ejecuta el instalador

        Ejecuta el instalador y sigue las instrucciones.
      </Step>
      <Step>
        ### Inicia Dockerman

        Inicia Dockerman y, si quieres la ruta integrada del Docker Engine, usa el Asistente de configuración WSL2 en el primer inicio. Consulta la [guía de la plataforma Windows](/es/docs/platform/windows).
      </Step>
    </Steps>
  </Tab>
  <Tab>
    <Steps>
      <Step>
        ### Instala el paquete

        Instala el paquete que coincida con tu distribución. Usa el build `.deb`, `.rpm` o AppImage y sigue la [guía de la plataforma Linux](/es/docs/platform/linux).
      </Step>
      <Step>
        ### Añade tu usuario al grupo docker

        Ejecuta:

        ```bash
        sudo usermod -aG docker $USER
        ```

        Cierra sesión y vuelve a iniciarla para que la membresía del grupo surta efecto.
      </Step>
      <Step>
        ### Inicia Dockerman

        Inicia Dockerman desde el menú de escritorio. Los paquetes publicados no prometen un ejecutable GUI `dockerman` en `PATH`.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Primer inicio

<Steps>
  <Step>
    ### El diálogo de conexión

    Dockerman intenta conectarse al Docker local y muestra el progreso o los errores.

  </Step>
  <Step>
    ### Elige una fuente de runtime

    Selecciona el socket local, un endpoint TCP o un host SSH. Fija la preferencia de runtime en Auto, Docker o Podman. Auto detecta el runtime disponible: primero Docker y, si no hay, Podman.
  </Step>
  <Step>
    ### Inicialización de datos

    Dockerman carga contenedores, imágenes, redes, volúmenes y proyectos Compose en paralelo.
  </Step>
  <Step>
    ### El panel de control

    Revisa una instantánea de los contenedores en ejecución y detenidos, más gráficos en tiempo real.

  </Step>
</Steps>

## Requisitos del sistema

| Plataforma | Versión mínima | Arquitectura |
| --- | --- | --- |
| macOS | 11 (Big Sur) | Intel, Apple Silicon, Universal |
| Windows | Builds soportadas de Windows 10 / 11 | x86_64 |
| Linux | Distribución de escritorio moderna | x86_64 |

Necesitas un endpoint compatible de Docker o Podman. El proyecto no publica una matriz de versiones mínimas de motor probadas por separado. Windows puede aprovisionar Docker con la ruta WSL2 opcional.
