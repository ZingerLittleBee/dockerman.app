---
title: Debug Assistant
description: Forward an existing process's debug port and generate an editor attach configuration.
---

Debug Assistant connects a local debugger to a process that is already running in a Pod. It creates a Kubernetes port forward and generates an attach configuration for your editor.

## Start a debug session

1. Select an existing Pod and container.
2. Choose a supported debugger preset or enter the remote debug port and remote source path.
3. Start the session.
4. Copy the generated attach JSON into the matching editor configuration.
5. Stop the session when finished to close the port forward.

## What Debug Assistant does not do

<Callout type="warn">
  Dockerman does not create an ephemeral toolbox Pod, inject debugging tools, share another Pod's process or network namespace, mount its volumes, or open a debug terminal. The target process must already expose and listen on the selected debug port.
</Callout>

Use the regular [Pod terminal](/en/docs/kubernetes/logs-terminal) when the selected container already contains a usable shell.
