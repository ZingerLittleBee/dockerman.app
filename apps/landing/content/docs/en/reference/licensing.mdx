Local Docker features do not require a license. Activate, manage, or reset a license when you need remote host connections.

## Overview

Local Docker features are free and do not require a license. The only paid feature is remote host connections, including SSH and multi-host management. Dockerman prompts you to activate a license only when you connect a remote host. See [Pricing](/en/pricing) for current plans.

## Activate

<Steps>
  <Step>
    ### Open Settings → License

    Paste your license key into the License settings page.
  </Step>
  <Step>
    ### Verify online

    Dockerman contacts the license server to verify the key.
  </Step>
  <Step>
    ### Confirm activation

    The status changes to Active, and Dockerman stores the license key and device identifier locally.
  </Step>
</Steps>

## Manage devices

Each activation is bound to a device identifier. If you replace a machine, lose access to one, or reach the device limit, open [License Self-Service](https://license.dockerman.app/manage) and enter the purchase email and license key. The public license policy allows resetting all linked devices once every seven days. Follow the confirmation instructions sent by the service; Dockerman does not publish a guaranteed email-link lifetime in this documentation.

## Startup and offline verification

Dockerman verifies the stored Ed25519 signature locally and also attempts an online revalidation on every launch. If the network request fails, the last valid license remains usable during a grace period. After 30 days without a successful validation, Dockerman removes the stored license and requires activation again.

## Troubleshooting

<Accordions>
  <Accordion title="Activation fails with network error">
    Check your firewall and proxy settings, then try the activation again from Settings → License. If the error persists, use [License Self-Service](https://license.dockerman.app/manage).
  </Accordion>
  <Accordion title="Device limit reached">
    Use [License Self-Service](https://license.dockerman.app/manage) to deactivate all devices, then activate the license again on the machines you still use.
  </Accordion>
  <Accordion title="License invalid after an update">
    Try reactivating the license first. If that does not help, email [support@dockerman.app](mailto:support@dockerman.app) and attach the App Log export.
  </Accordion>
</Accordions>
