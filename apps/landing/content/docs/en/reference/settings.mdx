---
title: Settings
description: Reference for the settings currently available in Dockerman.
---

Settings use a left navigation and a scrollable panel. Open them from the gear button, the system tray, or [Spotlight](/en/docs/advanced/spotlight).

## General

General contains:

- License activation and status
- Default container terminal shell (`/bin/sh`, `/bin/bash`, `/bin/zsh`, or a custom path)
- Menu bar style: standard icon or CPU/memory statistics
- The customizable Spotlight shortcut, which defaults to `Cmd/Ctrl + ;`

Terminal font, cursor, theme, close-to-tray behavior, and tray menu editing are not settings in the current app.

## Sidebar

Choose which main and Kubernetes navigation items are visible. Hiding an item removes it from the sidebar; it does not disable the underlying feature. Use **Reset** to restore the defaults.

## Engine

Choose Docker or Apple Container as the local engine. Docker settings include:

- Runtime preference: Auto, Docker, or Podman
- Local socket or TCP connection
- Custom socket path and connection test
- Image upgrade watch settings

Dockerman does not currently start, stop, or resize Colima or Podman machines. See [Colima & Podman](/en/docs/platform/colima-podman).

## Kubernetes

Configure port-forward defaults and automatic DNS. DNS registrations are created when a port forward starts; there is no separate enable switch. Platform resolver setup is documented in [Port Forward & DNS](/en/docs/kubernetes/port-forward).

## Apps

Configure application template sources and the host data root used by Apps.

## Notifications

The current page lists configured channels and can send a test notification. A complete add, edit, disable, and delete workflow is not available in the current desktop UI. See [Notifications](/en/docs/homelab/notifications) for storage and security details.

## Security

Security contains:

- Trivy binary, version, update, and scan defaults when the connected engine supports Trivy
- Anonymous product analytics

Analytics is enabled by default and can be disabled here. The current app has no crash-reporting switch.

## CLI

Install, update, or remove the bundled `dockerman` CLI and view install commands for the supported AI assistant integrations. See the [CLI overview](/en/docs/cli).

## Settings that do not exist

Dockerman currently has no Tasks settings panel or Settings → About page. Background task and alert creation workflows described elsewhere may also be unavailable; those pages state their current limitations.
