Compose 页根据 Docker Compose 标签发现项目，并提供当前 Docker 运行时支持的生命周期操作。Podman 目标不支持 Compose。

## 生命周期

根据项目状态可启动、停止、重启、拉取、up 或移除。卷移除选项会转发给 Compose，Dockerman 不会预先枚举全部命名卷或核对其他使用者。

## 编辑 YAML

在编辑器中打开项目 Compose 文件，保存后按需应用。保存前不会运行 `docker compose config`，编辑器也不承诺完整的 Compose schema 校验或自动补全。重要文件请另行验证。

## 转换 `docker run`

Run to Compose 会把常见 `docker run` 参数解析为 YAML 预览。保存与部署前请检查不支持或较高级的参数。

## 当前边界

本页目前没有项目级合并日志查看器。精选应用模板位于 **Apps**，不是 Compose 内置模板编辑器；也不能从本页把现有 Compose 文件保存成可复用模板。
