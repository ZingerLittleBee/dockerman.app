事件页从所选 Docker 主机接收事件，并提供搜索、筛选、详情和导出。

## 暂停行为

暂停后，新事件不会进入可见列表或持久化队列。暂停期间到达的事件会被丢弃，不会先缓冲再补播。

## 本地历史

Dockerman 在应用数据目录按主机保存 JSONL。单个文件达到 5 MiB 时轮转，最多保留 20 个轮转文件以及当前文件。当前没有按时间配置保留期的设置。

## 筛选与导出

使用页面实际显示的控件按资源类型、动作、时间和文本筛选。可用时将当前结果导出为 JSON 或 CSV。

<Callout type="warn">
  Docker 事件描述状态变化，不保证包含每个底层命令错误，也不能可靠标识是谁触发了操作。
</Callout>
