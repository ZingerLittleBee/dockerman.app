用这一页列出网络、创建新网络，以及连接或断开容器。

## 网络列表

网络列表显示名称、驱动、范围、附加容器数量和子网。内置网络如 `bridge`、`host` 和 `none` 会被标记，以免误删。

## 创建网络

<Steps>
  <Step>
    ### 选择名称和驱动

    Docker 运行时可选择 `bridge`、`host`、`overlay`、`macvlan` 或 `none`。Apple Container 不显示驱动选择器。
  </Step>
  <Step>
    ### 配置 IPAM（可选）

    如需自定义地址，请设置子网、网关和 IP 范围。
  </Step>
  <Step>
    ### 标签（可选）

    以后要组织或自动化管理网络时，加上键值标签。
  </Step>
</Steps>

<Callout type="info">
  Overlay 网络需要守护进程启用 Swarm 模式。
</Callout>

## 连接和断开容器

打开网络，选择"连接容器"，然后选择目标容器和可选别名。如需将容器从网络中移除，可在同一视图中使用"断开连接"。

## 检查网络

打开"检查"以查看网络 JSON，包括驱动选项、IPAM 设置以及已连接容器的 IP 地址和别名。

## 删除和清理

断开附加容器后，删除将移除单个网络。清理将移除未被至少一个容器使用的所有网络。

<Callout type="warn">
  内置网络（`bridge`、`host`、`none`）无法删除。清理会自动跳过它们。
</Callout>
