title: "日志"
description: "流式查看、搜索、筛选、复制和导出容器日志。"
---

从容器打开日志就能跟随输出。暂停只停止跟随最新一行，不会修改容器。

## 获取控件

选择时间预设或自定义范围，设置最多 10,000 行的 tail，并筛选 stdout 或 stderr。文本、大小写和正则搜索只作用于已加载行，不是服务端 Docker 日志查询。

## 键盘操作

已实现的快捷键包括 `/` 或 Ctrl/Cmd+F 聚焦搜索，Ctrl/Cmd+G 与 Shift+Ctrl/Cmd+G 切换匹配，`P` 暂停/跟随，Alt+C 切换大小写，Alt+R 切换正则，`g`/`G` 跳到最新/最旧，以及 Escape 清除搜索。`n`、`N`、Enter 和 Shift+Enter 不是已约定的查看器快捷键。

## 导出

使用工具栏复制或导出文本/JSON。时间戳显示来自已加载的 Docker 日志，查看器没有此前文档所述的相对时间、UTC、本地时间切换。
