Dockerman 提供 `.deb`、`.rpm` 或 AppImage，按当前发行版安装即可。

## 安装

<Tabs items={['.deb', '.rpm', 'AppImage']}>
  <Tab>
    ```bash
    sudo dpkg -i Dockerman_*_amd64.deb
    sudo apt-get install -f
    ```

    在 Debian 或 Ubuntu 上安装 `.deb` 包。
  </Tab>
  <Tab>
    ```bash
    sudo rpm -i Dockerman-*-1.x86_64.rpm
    # 或
    sudo dnf install Dockerman-*-1.x86_64.rpm
    ```

    在 Fedora 或 RHEL 上安装 `.rpm` 包。
  </Tab>
  <Tab>
    ```bash
    chmod +x Dockerman_*_amd64.AppImage
    ./Dockerman_*_amd64.AppImage
    ```

    AppImage 可直接运行，Dockerman 不提供 AppImage `--install` 参数。
  </Tab>
</Tabs>

## 配置 Docker Engine

请按照官方 Docker Engine 安装说明为你的发行版进行安装：[docs.docker.com/engine/install/](https://docs.docker.com/engine/install/)，然后确保守护进程正在运行。Dockerman 目前没有发布经过单独测试的 Docker Engine 最低版本。

## 权限

<Steps>
  <Step>
    ### 将你的用户添加到 docker 组

    ```bash
    sudo usermod -aG docker $USER
    ```
  </Step>
  <Step>
    ### 注销并重新登录

    组成员身份仅适用于新的登录会话。
  </Step>
  <Step>
    ### 验证访问权限

    无需 `sudo` 即可运行 `docker ps`。
  </Step>
</Steps>

<Callout type="warn">
  加入 `docker` 组实际上相当于拥有主机的 root 权限。如果你需要更严格的隔离边界，请使用 rootless Docker。
</Callout>

## 显示服务器

Dockerman 可在 Wayland 或 X11 下运行。全局快捷键行为取决于桌面环境及其 Tauri/WebView 集成；Dockerman 没有单独实现 xdg-desktop-portal 快捷键后端。

## Freedesktop 集成

Dockerman 会安装一个 `.desktop` 文件，使其出现在你的应用程序菜单中。托盘图标使用 StatusNotifierItem 规范，KDE、GNOME（需扩展）、XFCE 和 MATE 均支持该规范。

## 故障排除

<Accordions>
  <Accordion title="找不到 docker 命令">
    请先安装 Docker Engine，然后打开一个新的 shell，以便 PATH 能够识别 Docker CLI。
  </Accordion>
  <Accordion title="/var/run/docker.sock 权限被拒绝">
    将你的用户添加到 `docker` 组，然后注销并重新登录，以使新的组成员身份生效。
  </Accordion>
  <Accordion title="托盘图标缺失">
    为你的桌面环境安装 StatusNotifierItem 扩展。GNOME 通常需要 AppIndicator 和 KStatusNotifierItem 支持。
  </Accordion>
</Accordions>
