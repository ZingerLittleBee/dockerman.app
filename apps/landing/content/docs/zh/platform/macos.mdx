---
title: "macOS"
description: "在 macOS 上通过 Docker Desktop、兼容 socket 或 Apple Container 运行 Dockerman。"
---

macOS 上 Dockerman 发的是 Universal DMG。安装前请在发布页面核对当前资产及其签名。

## 安装

<Steps>
  <Step>
    ### 下载 DMG

    从发布页面下载 Universal DMG。
  </Step>
  <Step>
    ### 打开并拖入应用程序文件夹

    打开 DMG 并将 Dockerman 拖入应用程序文件夹。
  </Step>
  <Step>
    ### 启动 Dockerman

    从应用程序文件夹或 Spotlight 启动 Dockerman，如果 macOS 提示首次启动授权，请批准。
  </Step>
</Steps>

## 容器后端

Dockerman 可连接 Docker Desktop 或其他兼容 Docker 的 socket。如果自动检测失败，请在设置 → Docker 中填写自定义 socket 路径。

<Callout type="info">
  兼容 Docker 的 socket（如 `/var/run/docker.sock` 和 `~/.docker/run/docker.sock`）也可以使用。如果 Dockerman 未能自动检测到你的 socket，请在设置 → Docker 设置中设置路径。
</Callout>

在运行 macOS 26 或更高版本的 Apple Silicon Mac 上，Dockerman 还提供 Apple Container 后端。可在引擎引导或设置中选择 **Apple Container**。Intel Mac 和较早的 macOS 不支持该后端。

## 菜单栏和托盘

Dockerman 会在菜单栏添加常用操作图标。你可以在设置 → 通用中选择普通图标或 CPU/内存状态样式。

## Apple Silicon 注意事项

在 Apple Silicon 上运行容器前，请先确认镜像平台。许多公共镜像默认为 `amd64`，因此应尽量使用 `arm64` 版本，或显式设置 `--platform=linux/arm64`。

## 故障排除

- “Socket not found” 表示 Docker Desktop 未运行，或 Dockerman 使用了错误的 socket 路径。
- 如果 Gatekeeper 阻止 Dockerman 启动，请右键点击应用，并在首次启动时选择**打开**。
