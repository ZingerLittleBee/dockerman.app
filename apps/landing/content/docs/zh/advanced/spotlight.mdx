Spotlight 是 Dockerman 的命令面板。一键即可打开可搜索、键盘驱动的启动器，你可以在应用中导航到任意位置、执行常用操作并查找资源。

## 打开 Spotlight

默认按下 `Cmd/Ctrl + ;`，或从托盘菜单打开 Spotlight。Spotlight 以独立的无边框窗口打开，同时保持主 Dockerman 窗口在后台运行。

## 导航到资源

开始输入容器名称、镜像标签或 Compose 项目。按下 `Enter` 会打开选中的结果或操作。Dockerman 目前不会按使用频率或最近使用时间排序。

## 快捷操作

当 Spotlight 显示内联操作时，直接从结果列表中使用它们。

- 容器：启动、停止、重启、日志、终端、备份和诊断包
- 镜像：使用面板当前显示的镜像操作
- Compose 技术栈：生命周期操作、编辑 YAML 和诊断包
- 工具：Docker Run to Compose

## 搜索高亮

搜索遵循命令面板当前的文本匹配行为。Dockerman 没有额外定义使用频率排序或独立的匹配高亮契约。

## 自定义快捷键

在 [快捷键设置](/zh/docs/reference/settings#快捷键设置) 中更改 Spotlight 快捷键。

## 使用技巧

<Callout type="info">
  Spotlight 在独立的 Tauri 窗口中运行，因此可以保持即时响应。关闭 Spotlight 不会关闭主 Dockerman 窗口，反之亦然。
</Callout>
