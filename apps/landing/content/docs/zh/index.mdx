Dockerman 在桌面上集中管理 Docker、Podman 和 Kubernetes。面向希望用原生应用把容器、镜像和集群操作放在同一流程里的开发者和运维人员。覆盖 Docker 和 Podman 的本地与远程主机操作，以及 Kubernetes 的工作负载浏览和调试。

## Dockerman 涵盖的内容

Docker 和 Kubernetes 分开展示，本地容器任务和集群工作不必换工具。Docker 主机、镜像、卷和 Compose 项目放在一侧，需要工作负载、服务、配置、Helm 或 Pod 调试时再切到 Kubernetes。从下面的卡片开始。

## 核心功能

<Cards>
  <Card title="完整的 Docker 生命周期">
    创建、运行、检查、查看日志并进入容器终端；在一个地方管理镜像、网络、卷和 Compose 项目。
  </Card>
  <Card title="原生 Kubernetes（第一阶段）">
    一键启动 k3d 或导入你自己的 kubeconfig；浏览工作负载、Service、ConfigMap、RBAC、CRD 和 Helm 发布。
  </Card>
  <Card title="备份与恢复">
    将容器的配置、文件系统和卷快照打包为单个 tar.gz 文件，并在任何地方恢复（v4.8.0 新增）。
  </Card>
  <Card title="镜像安全">
    用 Trivy 扫描镜像，浏览 Docker Hub 不必离开应用（v4.6.0 新增）。
  </Card>
  <Card title="WSL2 Docker 引擎">
    在 Windows 上不必安装 Docker Desktop 也能运行 Docker。Dockerman 会自动设置 Alpine WSL2 发行版并安装 Docker（v4.3.0 新增）。
  </Card>
  <Card title="远程主机">
    通过 SSH 隧道连接远程 Docker 守护进程，并在主机之间切换。
  </Card>
  <Card title="Podman 运行时支持">
    使用 Podman 作为 Docker 的替代运行时。Dockerman 自动检测运行时并相应调整 UI（v5.1.0 新增）。
  </Card>
  <Card title="Homelab 自动化">
    后台任务调度器、多渠道通知（Telegram、ntfy、Gotify、Discord、Webhook）、告警规则、镜像升级监控和一键诊断包。
  </Card>
</Cards>
