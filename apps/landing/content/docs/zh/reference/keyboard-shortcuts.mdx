---
title: "键盘快捷键"
description: "Dockerman 当前支持的应用级键盘快捷键。"
---

Dockerman 只注册下列快捷键。能改的只有命令面板快捷键，入口在[设置 → 快捷键设置](/zh/docs/reference/settings#快捷键设置)。

## 全局

| 快捷键 | 操作 |
| --- | --- |
| Cmd/Ctrl + ; | 打开或关闭命令面板。此快捷键可以自定义。 |
| Cmd/Ctrl + B | 展开或收起侧栏 |

## 命令面板

| 快捷键 | 操作 |
| --- | --- |
| Up / Down | 在可用命令之间移动 |
| Enter | 执行选中的命令 |
| Esc | 返回上一层；位于首页时关闭命令面板 |
| Backspace | 搜索框为空时返回上一层 |

## 资源搜索

容器、镜像、网络、卷、文件以及部分 Kubernetes 列表支持以下搜索快捷键：

| 快捷键 | 操作 |
| --- | --- |
| Cmd/Ctrl + F | 聚焦并选中当前页面的搜索框内容 |
| / | 当前焦点不在可编辑控件中时，聚焦并选中搜索框内容 |
| Esc | 清除当前搜索，并让搜索框保持焦点 |

支持键盘导航的行或卡片在获得焦点后，可以通过 `Enter` 或 `Space` 打开。此行为只适用于相应的可交互项目，并非所有列表都支持。

## 文件浏览器

| 快捷键 | 操作 |
| --- | --- |
| Cmd/Ctrl + Click | 将项目加入选择或从选择中移除 |
| Shift + Click | 从上次选择的项目开始添加一个连续范围 |
| Space | 选择当前聚焦的项目 |
| Enter | 打开当前聚焦的目录，或预览当前聚焦的文件 |
| Delete / Backspace | 打开所选项目的删除确认框 |

## 日志查看器

| 快捷键 | 操作 |
| --- | --- |
| Cmd/Ctrl + F 或 / | 聚焦并选中日志查询 |
| Enter | 查询框获得焦点时跳到下一个匹配项 |
| Shift + Enter | 查询框获得焦点时跳到上一个匹配项 |
| Cmd/Ctrl + G | 跳到下一个匹配项 |
| Cmd/Ctrl + Shift + G | 跳到上一个匹配项 |
| Alt + C | 切换大小写敏感匹配 |
| Alt + R | 切换正则表达式匹配 |
| P | 切换日志跟随状态 |
| g | 跳到最新日志 |
| Shift + G | 跳到最早日志 |
| Esc | 清除查询 |

## Docker 事件

| 快捷键 | 操作 |
| --- | --- |
| Cmd/Ctrl + F 或 / | 聚焦事件搜索框 |
| P | 暂停或恢复事件流 |
| g | 跳到最新事件 |
| Shift + G | 跳到最早事件 |
| Esc | 清除事件搜索 |

## 容器终端

键盘输入会直接发送到容器的伪终端，因此 shell 控制序列仍然有效：

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + C | 向当前进程发送中断控制序列 |
| Ctrl + D | 发送文件结束控制序列 |

Dockerman 没有另外注册复制、粘贴或清空终端快捷键。

## 自定义命令面板快捷键

打开[设置 → 快捷键设置](/zh/docs/reference/settings#快捷键设置)，选择当前的命令面板快捷键，然后按下新的组合键。重置会恢复为 `Cmd/Ctrl + ;`。
