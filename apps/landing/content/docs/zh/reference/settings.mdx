设置窗口使用左侧导航和可滚动面板。可通过齿轮按钮、系统托盘或 [Spotlight](/zh/docs/advanced/spotlight) 打开。

## 通用

通用设置包含：

- 许可证激活与状态
- 容器终端默认 shell（`/bin/sh`、`/bin/bash`、`/bin/zsh` 或自定义路径）
- 菜单栏样式：普通图标或 CPU/内存状态
- 可自定义的 Spotlight 快捷键，默认 `Cmd/Ctrl + ;`

当前应用没有终端字体、光标、主题、关闭时最小化到托盘或编辑托盘菜单等设置。

## 侧边栏

选择主导航和 Kubernetes 导航中显示的项目。隐藏只影响侧边栏，不会禁用功能。使用**重置**恢复默认值。

## 引擎

选择 Docker 或 Apple Container 作为本地引擎。Docker 设置包含：

- Auto、Docker 或 Podman 运行时偏好
- 本地 socket 或 TCP 连接
- 自定义 socket 路径和连接测试
- 镜像升级监控设置

Dockerman 当前不会启动、停止或调整 Colima/Podman machine 的资源。参见 [Colima 与 Podman](/zh/docs/platform/colima-podman)。

## Kubernetes

配置端口转发默认值和自动 DNS。DNS 注册在端口转发启动时自动创建，没有独立的启用开关。平台 resolver 配置参见[端口转发与 DNS](/zh/docs/kubernetes/port-forward)。

## Apps

配置应用模板来源和 Apps 使用的主机数据根目录。

## 通知

当前页面可以列出已配置渠道并发送测试通知。桌面 UI 尚未提供完整的添加、编辑、禁用和删除流程。存储和安全说明参见[通知](/zh/docs/homelab/notifications)。

## 安全

安全设置包含：

- 连接引擎支持 Trivy 时的二进制、版本、更新和扫描默认值
- 匿名产品分析

产品分析默认开启，可在此关闭。当前应用没有崩溃报告开关。

## CLI

安装、更新或移除 `dockerman` CLI，并查看受支持 AI 助手的安装命令。参见 [CLI 总览](/zh/docs/cli)。

## 不存在的设置

Dockerman 当前没有任务设置面板，也没有设置 → 关于页面。后台任务和告警创建流程也可能尚未开放，对应页面会明确说明限制。
