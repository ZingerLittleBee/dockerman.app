---
title: "调试助手"
description: "转发现有进程的调试端口，并生成编辑器 attach 配置。"
---

调试助手把本地调试器连接到 Pod 里已经在跑的进程。它会创建 Kubernetes 端口转发，并生成编辑器要用的 attach 配置。

## 启动调试会话

1. 选择现有 Pod 和容器。
2. 选择支持的调试器预设，或填写远程调试端口和远程源码路径。
3. 启动会话。
4. 把生成的 attach JSON 复制到对应编辑器配置。
5. 完成后停止会话并关闭端口转发。

## 不包含的能力

<Callout type="warn">
  Dockerman 不会创建临时工具 Pod、注入调试工具、共享其他 Pod 的进程或网络 namespace、挂载其卷，也不会打开调试终端。目标进程必须已经在所选端口上监听调试协议。
</Callout>

当容器本身包含可用 shell 时，请使用普通的 [Pod 终端](/zh/docs/kubernetes/logs-terminal)。
