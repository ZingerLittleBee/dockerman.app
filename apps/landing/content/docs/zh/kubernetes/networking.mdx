用网络页查看集群里的流量路径。Service、Ingress、Endpoint 和 NetworkPolicy 都可以在这里读，不必回到 `kubectl`。

## Services

Service 是工作负载的稳定入口。列表显示服务类型、ClusterIP 和端口。

- `ClusterIP` 用于集群内部流量。
- `NodePort` 需要节点级端口做临时访问时。
- `LoadBalancer` 当集群暴露外部负载均衡器时。
- `ExternalName` 当 Service 指向 DNS 名称而非选择器时。

有选择器的 Service 还会在列表中显示 Forward 按钮，用来启动到就绪后端 Pod 的[端口转发](/zh/docs/kubernetes/port-forward)。

详情视图显示完整的 Service 规格和 YAML。

## Ingresses

Ingress 用来查看进入集群的 HTTP 路由。列表显示主机、路径和后端 Service，详情视图显示 TLS 密钥、注解和规则表格。

## Endpoints

要看 Service 背后的原始后端地址时用 Endpoint。Service 没有健康后端时这个视图最有用。

## EndpointSlices

EndpointSlice 是 Kubernetes 当前为 Service 维护的服务发现对象。Dockerman 在旧式 Endpoints 之外提供单独的列表与详情路由。

## NetworkPolicies

NetworkPolicy 用来看哪些 Pod 可以相互通信。

<Callout type="info">
  创建仅支持 YAML — 使用 YAML 编辑器编写新的 NetworkPolicy。
</Callout>

## 删除

Service、Ingress 和 NetworkPolicy 的列表视图均提供内联删除。完整支持内联删除的资源列表请参阅[工作负载 → 删除操作](/zh/docs/kubernetes/workloads#删除操作)。
