所有工作负载资源类型都在这一页。用列表查看状态，打开详情执行操作，要直接改对象时进入 YAML 编辑器。

## Pods

打开 Pod 查看状态和容器详情。需要 shell 时使用 [Pod 日志与终端](/zh/docs/kubernetes/logs-terminal)；[调试助手](/zh/docs/kubernetes/debug)只负责转发现有进程已经监听的调试端口。

在列表视图中删除 Pod，以强制重启或移除卡住的 Pod。

### 强制删除

**强制删除**会发送 `gracePeriodSeconds: 0` 并跳过优雅关闭，但不会移除 finalizer，因此被 finalizer 阻塞的 Pod 仍可能停留在 Terminating。

<Callout type="warn">
  强制删除会立即从 API 中删除 Pod，而不等待 kubelet 的确认。如果底层容器仍在节点上运行，可能会留下残留进程 — 仅在常规删除被阻塞时使用此操作。
</Callout>

## Deployments

用 Deployments 管理副本。

列表显示就绪、已更新和可用的副本数量，用来查看健康状况。

<Steps>
  <Step>
    ### 扩展

    直接修改副本数量并保存。
  </Step>
  <Step>
    ### 重启

    触发滚动重启以应用新的 ConfigMap 值，或强制重新拉取相同镜像标签。
  </Step>
</Steps>

## StatefulSets

StatefulSets 提供有序的 Pod 名称、稳定的标识和持久化存储模板。详情视图显示当前副本数量和关联的 Pod。扩展和重启操作与 Deployments 相同。

## DaemonSets

要在每个匹配节点上跑一个 Pod 时用 DaemonSets，例如日志收集器、监控代理或节点级网络组件。

## Jobs

Jobs 用来跑一次性完成的任务。在列表和详情视图中跟踪完成数量、退避限制和活跃期限。运行结束且不再需要时，可以从列表中删除 Job。

## CronJobs

要定时跑 Jobs 时用 CronJobs。在详情视图中查看 cron 表达式、暂停状态、上次运行时间和手动触发控件。

## ReplicaSets

ReplicaSets 通常位于 Deployment 之下。检查控制器状态时打开它，但应该编辑 Deployment 而不是直接修改 ReplicaSet。

<Callout type="info">
  Deployments 管理它们自己的 ReplicaSets。除非你在调试控制器行为，否则请修改 Deployment。
</Callout>

## HorizontalPodAutoscalers

HPA 页面列出 autoscaling/v2 资源，并显示目标、副本上下限、当前/期望副本、状态和时长。可调整最小/最大副本、检查 YAML 或删除 HPA。

## 使用 YAML 编辑工作负载

点击编辑 YAML 可修改完整对象。Dockerman 会在应用前执行**服务端 dry-run**，但不承诺客户端 Kubernetes schema 自动补全或校验。

### Dry-run 预览

在 YAML 编辑器中点击**预览变更**可执行服务端 dry-run，并将渲染后的对象与线上对象进行差异比较。差异会高亮字段的新增、删除和修改，应用前可以据此发现意外编辑。

## 删除操作

除了 Pod、Job、ConfigMap 和 Secret，列表视图中的内联删除还可用于 Service、Ingress、CronJob、DaemonSet、Deployment、StatefulSet 和 NetworkPolicy。Job 删除在本地化确认后会级联删除其所属的 Pod。
