---
title: "自定义资源"
description: "发现 CRD，并查看或编辑自定义资源实例。"
---

Dockerman 从当前集群发现 CustomResourceDefinition，列出 API group、Kind、scope、served versions 和 age。

选择 CRD 后可浏览其实例。实例表显示名称、适用时的 namespace 以及可用操作。你可以查看对象，并通过与其他支持资源相同的 server dry-run 和冲突检查编辑 YAML。

## 当前限制

- CRD 表不会计算实例数量。
- Dockerman 不渲染 Kubernetes printer columns。
- 编辑器不会加载 CRD OpenAPI schema，因此没有客户端 schema 校验或自动补全。
- 最终接收和校验结果以 Kubernetes API server 为准。

即使 CRD 自身声明了附加列或结构化 schema，上述限制仍然适用。
