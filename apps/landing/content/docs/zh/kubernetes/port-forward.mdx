---
title: "端口转发与 DNS"
description: "转发 Pod、Service 或 Deployment 端口，并配置 Dockerman 本地 DNS。"
---

把 Pod、Service 或 Deployment 的端口转发到本机。活动转发可按 Kubernetes 设置自动重连。

## 启动转发

1. 打开支持的资源并选择**端口转发**。
2. 选择远程端口和可用的本地端口。
3. 启动转发并使用页面显示的本地地址。
4. 完成后从活动转发列表中停止。

## 自动 DNS

转发启动时，Dockerman 会注册 `<target>.<namespace>.<suffix>` 形式的本地域名。默认 suffix 为 `k8s.local`，内置 UDP DNS 监听端口默认为 `5353`。

DNS 没有独立启用开关，Dockerman 也不会修改 `/etc/hosts`。

### 平台 resolver 配置

- macOS：配置 `/etc/resolver/<suffix>` 并指向 Dockerman DNS 端口。
- Linux：配置 systemd-resolved 或其他 resolver，把所选 suffix 发送到本地 DNS。
- Windows：当前尚未实现系统 resolver 自动集成。

修改 suffix 或端口会影响之后的注册；现有应用可能缓存 DNS 结果。
